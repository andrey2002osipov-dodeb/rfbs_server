# rfbs_server — Ozon rFBS на сервере

Серверная версия программы [Ozon rFBS](https://github.com/digushok/rfbs) (остатки и статусы заказов rFBS). Работает круглосуточно на OpenMediaVault в Docker. Интерфейс открывается в браузере с компьютера и с телефона через Tailscale, на телефоне ставится как приложение (PWA).

- **Установка:** [docs/OMV.md](docs/OMV.md)
- **Как пользоваться программой:** [app/README.md](app/README.md) (README автора)
- **Что изменено относительно программы автора:** [docs/CHANGES.md](docs/CHANGES.md)

## Чем отличается от Windows-версии

- Работает на сервере постоянно: не зависит от того, включён ли компьютер.
- Вход по логину и паролю, можно завести несколько пользователей. Магазины общие для всех, у каждого магазина свои данные.
- Мобильная вёрстка: вкладки внизу, таблицы карточками, крупные кнопки. Программу можно установить на главный экран телефона.
- Нет кнопок «Закрыть программу» и «Открыть папку»: на сервере они не нужны.

## Структура

```
app/                программа (исходники автора, версия в app/VERSION) + серверные дополнения
  server.go         серверный режим: вход, пользователи, сессии, защита запросов
  static/server.js  интерфейс серверного режима: выход, пользователи, PWA
  static/mobile.css мобильная вёрстка и страница входа
  static/login.html страница входа
Dockerfile          сборка образа
docker-compose.yml  файл для OpenMediaVault (Службы → Compose)
SERVER_VERSION      номер сборки серверной версии
.github/workflows/  тесты и публикация образа в ghcr.io
```

## Настройки (переменные окружения)

| Переменная | По умолчанию в образе | Что делает |
|---|---|---|
| `OZON_RFBS_ADDR` | `0.0.0.0:8766` | Адрес и порт. Включает серверный режим. Без переменной программа работает как настольная. |
| `OZON_RFBS_DATA` | `/data` | Папка данных. |
| `OZON_RFBS_ADMIN_USER`, `OZON_RFBS_ADMIN_PASSWORD` | — | Первый пользователь. Используется, только пока пользователей нет. |
| `PUID`, `PGID` | `1000`, `100` | От какого пользователя работает программа в контейнере. |
| `TZ` | `Europe/Moscow` | Часовой пояс. |

## Сборка и тесты

```bash
cd app && go test ./...
```

```bash
docker build -t rfbs_server .
```

Локальный запуск серверного режима без Docker:

```bash
cd app && OZON_RFBS_ADDR=127.0.0.1:8766 OZON_RFBS_DATA=./data-dev OZON_RFBS_ADMIN_USER=admin OZON_RFBS_ADMIN_PASSWORD=password1 go run .
```

## Обновление на новую версию программы автора

1. Скачать исходники нового релиза `digushok/rfbs` и разложить их поверх `app/`, сохранив серверные файлы. Список того, что изменено в файлах автора, — в [docs/CHANGES.md](docs/CHANGES.md).
2. Перенести правки из CHANGES.md, если файлы автора их затёрли. Прогнать `go test ./...`.
3. Если менялись только наши файлы — поднять `SERVER_VERSION`.
4. Запушить. GitHub Actions соберёт образ, на OMV нажать Pull и Up.
