# Изменения относительно программы автора (digushok/rfbs 1.8.0)

Все изменения работают только в серверном режиме (задана `OZON_RFBS_ADDR`). Без неё программа ведёт себя как исходная. Это проверяют тесты автора, они проходят без изменений.

## Новые файлы

| Файл | Что делает |
|---|---|
| `app/server.go` | Серверный режим: пользователи (`users.json`, PBKDF2-SHA256), подписанные сессии в cookie (60 дней), вход и выход, защита от подбора пароля (10 попыток за 15 минут), проверка Origin вместо проверки 127.0.0.1. |
| `app/server_test.go` | Тесты входа, сессий, пользователей и выбора магазина. |
| `app/static/server.js` | Кнопка выхода, раздел «Пользователи», подписи ячеек для мобильных карточек, регистрация service worker. Свёрнутые карточки целевых заказов на телефоне: стрелка раскрывает заказ, раскрытые запоминаются по номеру отправления. |
| `app/static/mobile.css` | Мобильная вёрстка (до 760 px), страница входа. С 1.7.0 — крупные кнопки «Начать / Пауза / Закончить», настройки в одну колонку, переключатели под палец. С 1.8.0 — целевые заказы в окошке на 60% высоты экрана со своей прокруткой; свёрнутый заказ показывает номер, партию, создан, статус Ozon и «что дальше». При новой версии автора проверить, что селекторы из этого файла есть в `index.html`. |
| `app/static/login.html` | Страница входа. |
| `app/static/manifest.webmanifest`, `sw.js`, `icon-*.png`, `apple-touch-icon.png` | PWA: установка на телефон. Service worker ничего не кэширует. |

## Правки в файлах автора

| Файл | Правка |
|---|---|
| `main.go` | Серверный режим: слушать `OZON_RFBS_ADDR`, не открывать браузер, лог в stdout, вход перед всеми страницами (`srv.wrap`), аккуратная остановка по SIGTERM (`docker stop`) без сброса флага «автоматизация включена». Статика отдаётся с `Cache-Control: no-cache`. |
| `store.go` | `dataDir()`: папка из `OZON_RFBS_DATA`, если задана. |
| `api.go` | Проверка Host/Origin вынесена в `apiRequestAllowed()` (в настольном режиме логика прежняя). `/api/state?id=…` возвращает выбранный в этом браузере магазин и в серверном режиме поля `server`, `server_version`, `user`. `/api/quit` и `/api/open-dir` на сервере отключены. |
| `static/index.html` | Подключены `mobile.css`, `server.js`, манифест и мета-теги PWA. Иконки у вкладок, кнопка выхода, карточка «Пользователи», `id` у нескольких заголовков, текст «по часам этого устройства». |
| `static/app.js` | При ответе 401 — переход на `/login`. Выбранный магазин хранится в `localStorage` браузера и передаётся в `/api/state?id=`. В тексте об обновлении для сервера нет ссылки на `.exe`. |

## Как переносилась версия 1.7.0

1. Ветка `upstream-import` от коммита «Импорт исходников rfbs 1.5.2»: в `app/` разложены исходники 1.7.0 без изменений (кроме `.github/`, он не нужен), коммит.
2. Эта ветка влита в основную (`git merge`): git сам перенёс серверные правки. Конфликт был только в `static/index.html` — взята разметка автора, возвращены `id="dataNote"` и «по часам этого устройства».
3. В `mobile.css` убраны правила для удалённых элементов (`#runBtn`, `.auto`, `.tplbar`, `#queueReset`) и добавлены для новых (`.qbar`, `#qStart`, `#qPause`, `#qFinish`, `.switch`).

Следующую версию удобно переносить так же: обновить `upstream-import` новыми исходниками и влить её в основную ветку.

## Версия 1.8.0

Перенесена так же: `upstream-import` ← исходники 1.8.0, затем `git merge` — без конфликтов.
