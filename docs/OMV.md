# Установка на OpenMediaVault

Инструкция для OMV 8 (подойдёт и для 7). Программа работает в Docker-контейнере. Интерфейс открывается в браузере на компьютере и на телефоне через Tailscale.

## 1. Плагин Compose

Если плагина ещё нет:

1. **Система → Плагины**. Если списка omv-extras нет, сначала установите omv-extras по SSH:

   ```bash
   wget -O - https://github.com/OpenMediaVault-Plugin-Developers/packages/raw/master/install | bash
   ```

2. Найдите **openmediavault-compose** и нажмите «Установить».
3. **Службы → Compose → Настройки**:
   - в поле «Shared folder» выберите или создайте общую папку для контейнеров, например `compose`;
   - нажмите «Сохранить».
4. Если Docker ещё не установлен, на той же странице нажмите «Reinstall Docker» и подождите.

## 2. Контейнер программы

1. **Службы → Compose → Файлы → «+ Создать»**.
2. Имя: `rfbs`.
3. В поле «Файл» вставьте содержимое [`docker-compose.yml`](../docker-compose.yml) из этого репозитория.
4. **Замените пароль** в строке `OZON_RFBS_ADMIN_PASSWORD` на свой. Он должен быть не короче 8 символов.
5. Нажмите «Сохранить». Потом выберите файл `rfbs` в списке и нажмите **Up** (стрелка вверх).
6. Проверка: **Службы → Compose → Контейнеры**. У `rfbs` должен быть статус `running`, а через полминуты — `healthy`.

Данные программы (магазины, ключи, партии, журналы) лежат в общей папке Compose, в подпапке `rfbs/data`. Включите её в резервное копирование.

> Логин и пароль из compose-файла используются **только при первом запуске**. Потом пароли меняются в программе: «Настройки → Пользователи». После первого входа строку с паролем можно стереть из файла.

## 3. Открыть программу

**В домашней сети:** `http://<IP-сервера>:8766`.

**Через Tailscale, по IP:** `http://<Tailscale-IP-сервера>:8766`. IP сервера в Tailscale начинается со `100.`, его видно в приложении Tailscale. Работает сразу. Но браузер не считает такой адрес защищённым, поэтому на Android программу не получится установить как приложение.

**Через Tailscale, по HTTPS (рекомендуется):** адрес вида `https://kucha.<ваша-сеть>.ts.net`. На телефоне программа ставится как приложение, вход защищён шифрованием.

1. Если Tailscale работает в Docker-контейнере (`docker ps` показывает контейнер `tailscale`), все команды `tailscale …` ниже выполняйте как `docker exec tailscale tailscale …`. Публикация программы в этом случае:

   ```bash
   docker exec tailscale tailscale serve --bg http://$(hostname -I | awk '{print $1}'):8766
   ```

   Чтобы вход в Tailscale не слетал при перезапуске, у контейнера должна быть подключена папка для `TS_STATE_DIR` (например `/var/lib/tailscale`).

   Если Tailscale на сервере нет совсем (ни команды `tailscale`, ни контейнера), установите его по SSH и войдите по ссылке, которую выведет `tailscale up`:

   ```bash
   curl -fsSL https://tailscale.com/install.sh | sh
   ```

   ```bash
   tailscale up
   ```

   В [панели Tailscale](https://login.tailscale.com/admin/machines) у сервера: ⋯ → **Disable key expiry**. Иначе примерно через полгода сервер выпадет из сети Tailscale и потребует входа заново.
2. В [панели Tailscale](https://login.tailscale.com/admin/dns) включите **MagicDNS** и **HTTPS Certificates**.
3. На сервере по SSH выполните:

   ```bash
   sudo tailscale serve --bg 8766
   ```

4. Команда выведет адрес `https://….ts.net`. Его и откройте.

Отключить HTTPS-адрес:

```bash
sudo tailscale serve --https=443 off
```

## 4. Телефон

1. Установите **Tailscale** (App Store или Google Play) и войдите в ту же учётную запись, что на сервере.
2. Откройте адрес программы и войдите.
3. Установите как приложение:
   - **iPhone (Safari):** кнопка «Поделиться» → «На экран „Домой“».
   - **Android (Chrome):** меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

На телефоне доступно всё, что и на компьютере: заказы, партии, очереди, журнал, настройки магазинов и пользователей. Вкладки находятся внизу экрана, таблицы показываются карточками.

## 5. Первая настройка

1. Войдите под пользователем из compose-файла.
2. **Настройки → Пользователи**: добавьте остальных. Все пользователи видят все магазины. Выбранный магазин запоминается на каждом устройстве отдельно, поэтому никто никому не переключает магазин.
3. **Настройки → Магазины на сервере → «+ Магазин»**, затем введите Client-Id и API-ключ. Дальше всё как в Windows-версии: склад, партии, тестовый режим, боевой режим. См. [README программы](../app/README.md).

> ⚠️ **Один магазин — одна программа.** Не включайте автоматизацию одного и того же магазина одновременно на сервере и в Windows-версии: запросы в Ozon будут дублироваться.

## 6. Обновление

Когда в репозитории появляется новая сборка (вкладка Actions → зелёная галочка):

1. **Службы → Compose → Файлы** → выберите `rfbs` → **Pull**, затем **Up**.
2. Данные и пароли сохраняются. Включённая автоматизация после перезапуска продолжит работу сама.

Версии видны внизу страницы программы. Например, «версия 1.5.2 · сервер 1-abc1234» — это версия программы автора и номер сборки сервера.

Откатиться на прошлую сборку: в compose-файле замените `:latest` на `:sha-<коммит>` (список на странице Packages репозитория) и нажмите Up.

## 7. Если что-то не так

| Что видно | Что сделать |
|---|---|
| Контейнер в статусе `Restarting` | `docker logs rfbs --tail 30`. «пароль: не короче 8 символов» — удлините пароль в compose-файле и нажмите Up. |
| Контейнер сразу останавливается | Compose → Контейнеры → `rfbs` → Логи. Если там «нет ни одного пользователя», значит не задан пароль в compose-файле. |
| Pull: `denied` или `unauthorized` | На GitHub: Packages → `rfbs_server` → Package settings → Change visibility → **Public**. |
| Не открывается с телефона | Включён ли Tailscale на телефоне? Открывается ли адрес на компьютере в домашней сети? |
| «Слишком много неудачных попыток» | Было 10 неверных паролей за 15 минут. Подождите 15 минут. |
| Забыт пароль единственного пользователя | По SSH удалите файл `users.json` в папке данных (`.../compose/rfbs/data/users.json`) и перезапустите контейнер. Будет создан пользователь из compose-файла. |
| Нужно смотреть логи | Compose → Контейнеры → `rfbs` → Логи, или файл `data/logs/app.log`. |
